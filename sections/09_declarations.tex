\section*{Disponibilité des données}

Les données et le code qui permettent de reproduire les résultats sont déposés dans des entrepôts publics, conformément à la politique de données de la revue. Les bases de scénarios des lots A et B, les fichiers d'hypothèses et de configuration, les trajectoires, les paramètres ajustés, la base d'apprentissage, les contraintes structurelles et le réseau bayésien appris sont déposés sur Mendeley Data [DOI à ajouter]. Le générateur Isomorph-Reborn est diffusé en code ouvert, avec son manuel d'utilisation, dans une version archivée [DOI Zenodo à ajouter]. L'outil BayesArtist, utilisé pour l'apprentissage et l'inférence, n'est pas diffusé ; l'apprentissage du réseau peut toutefois être reproduit avec tout logiciel de réseaux bayésiens qui apprend la structure et les paramètres à partir d'un fichier CSV et accepte des arcs interdits, par exemple Hugin, GeNIe (BayesFusion), le paquet R bnlearn ou la bibliothèque Python pgmpy. Les algorithmes de recherche disponibles différant d'un outil à l'autre, de légers écarts de structure sont possibles. Un matériel supplémentaire détaille les compléments de modélisation retirés du texte principal.
